# RDM Android app (Flutter)

A native Android client for your RDM home-server download manager. Log in, watch
live download progress, queue new downloads, and supply credentials for
login-protected links — all from your phone.

## What's here

This folder contains the Flutter **source** (`lib/`, `pubspec.yaml`). The
platform folders (`android/`, `ios/`) are generated by the Flutter tool and are
git-ignored.

## Build it (one-time setup)

1. Install the Flutter SDK: https://docs.flutter.dev/get-started/install
2. From this `app/` folder, generate the platform scaffolding:
   ```bash
   flutter create .
   ```
3. **Allow HTTP (cleartext) traffic** — your server is `http://…:3598`, not
   HTTPS, so Android blocks it by default. In the generated
   `android/app/src/main/AndroidManifest.xml`, add this attribute to the
   `<application …>` tag:
   ```xml
   <application
       android:label="RDM"
       android:usesCleartextTraffic="true"
       ...>
   ```
   (If you later put RDM behind HTTPS, you can remove this.)
4. Run on a connected device/emulator:
   ```bash
   flutter run
   ```
   Or build an installable APK:
   ```bash
   flutter build apk --release
   # output: build/app/outputs/flutter-apk/app-release.apk
   ```

## Configuration

- The **server URL** is set on the login screen (and in Settings) and saved on
  the device. Default: `http://192.168.31.70:3598`.
- Your phone must be on the same network as the server (or reach it via VPN /
  port-forward).

## Features

- Token (JWT) login against `/api/auth/login`, session persisted.
- Live download list (2s polling) with progress, status, and speed.
- Pause / resume / cancel / retry / delete.
- New download (URL, category, connections, AI-rename toggle).
- "Sign in & retry" prompt for downloads flagged `needs_auth`.
- Light / dark theme that follows the system.
